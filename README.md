# learning-c

![C](https://img.shields.io/badge/language-C-blue) ![Progress](https://img.shields.io/badge/progress-10%20programs-brightgreen)

My journey learning the C programming language, one small program at a time. Each file focuses on a single concept, building up from the basics to a small combined project.

## Progression

- `hello.c` — First program, basic printf
- `variables.c` — Variables, types and operators
- `entree_utilisateur.c` — Reading user input with scanf
- `conditions.c` — if / else / switch
- `boucles.c` — for / while / do while
- `fonctions.c` — Functions and prototypes
- `tableaux.c` — One and two-dimensional arrays
- `chaines.c` — Strings and string.h
- `pointeurs.c` — Introduction to pointers
- `structures.c` — Structures (struct)
- `carnet_contacts.c` — Mini-project combining every concept above (a command-line contact book)

## How to run

```bash
git clone https://github.com/awaba-dev/learning-c.git
cd learning-c
gcc nom_du_fichier.c -o programme
./programme
```
